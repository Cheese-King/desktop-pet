# 栖伴桌宠

一个面向 Windows 桌面的 Live2D 智能桌宠。项目把桌面陪伴、轻量任务管理、文档处理和本地语音能力组合在一起，让桌宠既能陪伴互动，也能协助完成日常工作。

## 项目特点

- **Live2D 桌面角色**：使用 Live2D Cubism 模型进行实时渲染，支持待机、表情、动作和互动反馈。
- **桌面陪伴**：桌宠常驻桌面，可拖动、缩放，并通过托盘菜单打开任务中心和设置。
- **智能对话**：支持本地对话工作流，可结合配置的模型服务进行聊天、上下文交流和角色化回复。
- **语音合成**：通过独立的 GPT-SoVITS 语音服务生成中文、日文、英文语音，并由桌宠播放语音反馈。
- **任务中心与轻量 Agent**：集中处理任务输入、待办事项、工作区文件和任务状态，并提供简单的 Agent 能力，可根据目标拆分步骤、调用工作区和文档工具、记录执行状态，再汇总返回结果。
- **文档能力**：支持读取和生成常见文档内容，包含 DOCX、PDF 等文件处理流程。
- **时间与天气**：提供时间卡片、天气信息和天气相关待办展示。
- **动作与视觉交互**：集成 MediaPipe 视觉能力，为摄像头动作捕捉和桌宠反馈提供基础支持。
- **本地优先**：桌面端运行逻辑、语音服务配置和工作区数据可以保存在本机，便于个人部署和调试。

## 技术组成

桌宠端基于 **Electron** 构建，使用 Node.js 运行主进程和本地服务，通过 Electron IPC 在主进程、预加载层与渲染界面之间传递消息。界面和交互输出位于 `out/renderer`，桌面窗口、任务、工作区、轻量 Agent、日志和系统能力位于 `out/main`，预加载桥接代码位于 `out/preload`。

项目使用 Live2D Cubism Core 渲染角色模型，使用 MediaPipe WASM 模块提供视觉分析能力；语音部分通过 `voice-service` 调用外部 GPT-SoVITS 环境，桌宠与语音服务之间通过本地 HTTP 接口协作。仓库中的构建产物已经包含运行所需的前端资源、Live2D 模型和 MediaPipe 文件。

## 启动方式

1. 准备 Node.js 运行环境和 GPT-SoVITS 推理环境。
2. 双击 `启动栖伴.bat` 或 `start.bat`。
3. 在语音服务配置中填写 GPT-SoVITS 根目录、参考音频和模型路径。
4. 启动桌宠后，可通过桌面右键菜单或托盘图标打开任务中心。

本仓库主要保存桌宠项目和构建输出，不包含完整的 Python/CUDA 运行时、GPT-SoVITS 大模型权重及训练环境。语音服务配置文件中的路径需要根据本机环境调整。
